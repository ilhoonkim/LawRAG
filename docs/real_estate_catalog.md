법령명은 공백 차이를 제외하고 정확히 일치하는 대상만 처리합니다. 명칭 변경의 전체 계보를 공식적으로 검증하는 기능은 없으며, 지정한 현행·과거 명칭의 API 응답 범위에서 수집합니다. 등기 지침 2개가 해당 API에 없으면 실패 사유를 기록합니다. 결과는 `data/preload-real-estate-report.json`과 기존 수집 이력에 남습니다.
