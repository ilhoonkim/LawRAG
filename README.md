# LawRAG

국가법령정보 공동활용 API에서 법령을 수집하고, 조 단위 하이브리드 검색과 근거 기반 AI 답변을 제공하는 로컬 개발용 앱입니다. 첨부 디자인의 좌측 대화 목록·청색 중앙 채팅·우측 출처 목록을 반영했습니다.

## 실행

Python 3.12 및 SQLite 확장 로드를 지원하는 환경이 필요합니다. 기본 실행 주소는 루프백으로 제한합니다. 인증 기능이 없는 개발용 앱이므로 공개 서버로 배포하려면 인증·접근 제어·호출량 제한을 추가하세요.

```bash
cd LawRAG
python -m venv .venv
# Linux / macOS
.venv/bin/python -m pip install -r requirements.txt
# 최초에만 실행. 기존 .env는 덮어쓰지 마세요.
cp -n .env.example .env
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Windows는 `.venv\\Scripts\\python.exe`를 사용하고 `.env.example`을 `.env`로 복사합니다. 로컬 PC에서는 브라우저로 `http://127.0.0.1:8000`을 엽니다. 클라우드 내부의 `/workspace/LawRAG` 경로는 PC 탐색기 경로가 아닙니다. 클라우드 UI가 파일 편집이나 포트 연결을 제공하지 않으면 프로젝트를 PC로 가져와 실행해야 합니다.

`.env` 또는 서버 프로세스 환경 변수:

| 이름 | 용도 |
|---|---|
| `LAW_API_OC` | 국가법령정보 공동활용 신청 시 사용하는 OC 식별값. 일반적인 무작위 API 키와 다릅니다. law 목록·본문 조회 권한이 필요합니다. |
| `LLM_API_KEY` | OpenAI API 키. 채팅에 붙여 넣거나 Git에 커밋하지 마세요. |
| `LLM_BASE_URL` | 기본 `https://api.openai.com/v1`. embeddings/chat completions 호환 서버로 변경 가능 |
| `EMBEDDING_MODEL` | 기본 `text-embedding-3-small` |
| `CHAT_MODEL` | 기본 `gpt-4.1-mini` |
| `SEARCH_THRESHOLD` | 기본 `0.48`, 검색 점수 최소값 |
| `DATA_DIR` | 기본 프로젝트 하위 `data`. 모델을 바꾸면 새 디렉터리로 전체 재색인 권장 |

이미 주입된 환경 변수가 `.env`보다 우선합니다. 변경 후 서버를 재시작하세요. `LLM_API_KEY`가 없으면 기존 `OPENAI_API_KEY`를 사용합니다. 키는 서버에서만 읽고 UI에 전송하지 않습니다.

실제 연결에 필요한 HTTPS 도메인은 `www.law.go.kr`, `api.openai.com`입니다. 공식 가이드는 `open.law.go.kr`입니다. 네트워크 제한 환경은 기존 허용 목록을 유지하면서 필요한 호스트를 추가하세요. 설치에는 Python 패키지 저장소 접근이 필요합니다.

## 사용 순서

1. **법령 수집·관리**에서 `선박안전법` 등을 검색합니다. 검색 결과의 시행일 및 법령 구분을 확인하고 원하는 버전을 수집합니다. 초기에는 법령이 자동으로 수집되지 않습니다.
2. API XML을 원본으로 저장하고 각 조의 본문·항·호·목을 합쳐 임베딩합니다. 기본 모드는 API 비용이 발생합니다. OC만 있으면 `임베딩 없이 수집`을 선택할 수 있습니다.
3. **키워드 + 임베딩** 모드에서 질문합니다. 임베딩 없이 수집한 자료는 **키워드 검색**으로 선택해야 하며, AI 답변에는 여전히 LLM 키가 필요합니다. 키 없이 근거 검색만 실행하려면 `/api/search` 또는 CLI를 사용하세요.
4. 답변 하단의 법령·조 버튼이나 우측 출처를 누르면 팝업이 열리고 해당 조로 이동합니다. 팝업의 공식 원문 링크로 수식·별표 등을 확인할 수 있습니다.
5. 대화는 현재 브라우저의 localStorage에 저장됩니다. 좌측 `삭제`로 이 기기의 이력을 지울 수 있습니다. 모바일에서도 상단 법령 관리와 답변 하단 출처를 사용할 수 있습니다.

## 모듈

- `app/laws.py`: 법령 검색/본문 API, XML 파싱, 안전한 HTML 생성. 원래 개행을 보존하고 항·호·목 사이에 개행 추가.
- `app/store.py`: SQLite + sqlite-vec 벡터 저장·코사인 검색, 키워드 검색, 트랜잭션 재색인.
- `app/provider.py`: OpenAI 호환 임베딩 및 LLM 답변. 질문·근거를 모델에 전달하고 번호 인용 요청.
- `app/main.py`: FastAPI. `/docs`에 API 스키마.
- `app/static/`: 외부 CDN 없는 반응형 채팅 UI, 이력, 수집 화면, 원문 팝업.
- `app/cli.py`: UI 없는 수집·검색 명령.

```bash
.venv/bin/python -m app.cli search-laws '선박안전법'
# 검색 응답의 법령일련번호(MST)를 사용하세요. 법령ID와 다릅니다.
.venv/bin/python -m app.cli ingest 실제_MST값
.venv/bin/python -m app.cli search '선박안전법에 적용되지 않는 것은?'
.venv/bin/python -m app.cli search '선박안전법 적용범위' --mode keyword --threshold 0.48
```

## 저장 및 검색 규칙

- `data/raw/<해시>.xml`: API 원본.
- `data/html/<해시>.html`: 불변 버전별 HTML. 섹션 ID는 `선박안전법-제3조`, 가지 조문은 `선박안전법-제30조의2` 형식. URL의 한글 앵커는 인코딩합니다.
- `data/laws.sqlite3`: 조문·법령 메타데이터·float32 벡터·임베딩 모델 식별자. sqlite-vec의 SQL 코사인 거리 연산을 이용하는 정확 검색이며, 대규모 ANN 인덱스는 아닙니다.
- 동일 법령ID는 마지막으로 선택해 수집한 버전만 검색합니다. 기존 답변에 연결된 HTML은 보존합니다. 여러 시행 버전의 동시 검색은 지원하지 않습니다.
- 키워드는 한국어 문자 2-gram으로 비교하고 조 제목에 가중치를 줍니다. 적용 제외 표현은 적용범위 관련 검색어로 확장합니다. 질문에 법령명이 명시되면 가장 길게 일치하는 법령명으로 제한합니다. 다중 법령 비교 질문은 각 법령을 따로 조회하세요.
- 하이브리드 점수 = 코사인 유사도(0~1로 제한) × 0.65 + 키워드 점수 × 0.35. 키워드 모드는 키워드 점수만 사용합니다. 임계치 이상 상위 5개가 기본이며 API에서 1~10개를 선택할 수 있습니다.
- 점수는 정답 확률이 아닙니다. 기본 임계치는 실제 질의 평가로 조정해야 합니다. 근거가 없으면 LLM을 호출하지 않습니다. 이전 대화는 답변 생성에만 전달하며 검색에는 현재 질문을 사용하므로 후속 질문에도 법령명·쟁점을 명시하세요.
- 원문에 없는 줄바꿈·수식·이미지·별표는 복원하지 않습니다. HTML은 조문 텍스트 뷰이며 공식 페이지를 완전히 복제하지 않습니다. 매우 긴 조문(24,000자 초과)은 오류로 보고하며 조용히 자르지 않습니다. 모델별 토큰 한도에 따라 더 짧은 입력도 API에서 거부될 수 있습니다.
- 근거를 제한하고 인용을 요청하지만 LLM 답변의 법률적 정확성이나 인용의 타당성을 자동 보증하지는 않습니다.

## 검증

```bash
.venv/bin/python -m pytest -q
node --check app/static/app.js
.venv/bin/python -m pip check
```

테스트 XML은 **합성 데이터이며 실제 법령이 아닙니다**. 파싱·줄바꿈·HTML 안전성·앵커·검색 임계치·제3조 우선순위·재수집·모델 불일치·API 연결 흐름을 테스트 더블로 검증합니다. 프로덕션 데이터 디렉터리에 테스트 법령을 자동 주입하지 않습니다.

실제 OC/키 및 네트워크 허용 후 법령 목록 조회 → 실제 MST 수집 → 적용 제외 질문 → 제3조 근거/원문 팝업 → 답변의 제외 대상과 단서 대조를 수행해야 실서비스 연결과 검색 품질을 확인할 수 있습니다. 현재 클라우드에서는 위 두 API 도메인에 프록시 403이 발생했으며 실제 API 호출 성공 및 실제 모델 검색 품질은 아직 검증하지 못했습니다.
